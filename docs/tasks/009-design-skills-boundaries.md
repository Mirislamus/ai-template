# 009 — Дизайн-навыки подчинены правилам шаблона

- **Уровень:** Medium
- **Статус:** готово
- **Источники:** запрос пользователя; [docs/skills.md](../skills.md) §2; [docs/design.md](../design.md) §9; правила навыков `$impeccable` 4.1.1, `$emil-design-eng`, плагина `frontend-design`
- **Цель:** стандартные правила дизайн-навыков не действуют в шаблоне; навыки работают только в границах правил проекта, а правила вкуса сформулированы через систему шаблона.
- **Обоснование оценки:** только документация, до 6 файлов, есть решения пользователя ([docs/workflow.md](../workflow.md) §1).

## Решения пользователя

- Правило касается `$impeccable`, `$emil-design-eng` и правил `frontend-design`.
- Навыки подчиняются, а не удаляются: `$impeccable` — только проверка и доработка готового интерфейса, его генерация и артефакты запрещены.
- Анти-шаблоны и порядок выбора палитры в docs/design.md §9 переписываются через токены, сетку и паспорта страниц.

## Критерии готовности

- [x] В docs/skills.md §2 описаны допустимые команды, запрещенные артефакты и таблица замены правил навыков правилами проекта.
- [x] Замечания навыков применяются только с опорой на правило проекта.
- [x] docs/design.md §9 опирается на токены, паспорта страниц и ADR, без ссылок на «сторонний skill вкуса».
