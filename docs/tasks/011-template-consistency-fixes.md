# 011 — Согласованность шаблона: порядок старта, задачи вне кода, охват проверок

- **Уровень:** Medium
- **Статус:** готово
- **Источники:** аудит шаблона по запросу пользователя; [docs/workflow.md](../workflow.md); [docs/setup/](../setup/common.md); ADR 0004 §13, ADR 0009, ADR 0010 §1, ADR 0023 §8; «Не исправлялось» из [007](007-template-audit-fixes.md)
- **Цель:** документы шаблона не противоречат друг другу в порядке старта проекта, задачи вне кода имеют уровень и исполнителя, а проверки `format` и `check` покрывают корневые конфиги и `packages/shared`.
- **Обоснование оценки:** только документация и эталонные конфиги, больше 5 файлов, есть решения пользователя ([docs/workflow.md](../workflow.md) §1).

## Решения пользователя

- История шаблона остается в шаблоне; при старте проекта ее удаляет шаг очистки в PROMPT.md.
- Документацию и инфраструктуру (CI, Nginx, Docker Compose, деплой) на любом уровне выполняет основной агент.
- Профиль (Astro или Next.js) записывается в PRODUCT.md; отдельного вопроса в допросе нет, агент выводит профиль по ADR 0001 §1 и подтверждает его в итоговом резюме.

## Критерии готовности

- [x] Порядок бэклога в docs/tasks.md совпадает с PROMPT.md: паспорта страниц до инициализации.
- [x] PROMPT.md и USAGE.md содержат шаг удаления истории шаблона.
- [x] docs/workflow.md задает уровень и исполнителя для документации и инфраструктуры.
- [x] В PRODUCT.md есть раздел профиля, PROMPT.md включает профиль в итоговое резюме.
- [x] Скрипты `format` и `format:check` покрывают корневые конфиги и `tests/`.
- [x] `packages/shared` имеет скрипт `check` и входит в корневой `bun run check`.
- [x] Эталонный ESLint фронтенда запрещает прямое чтение `process.env` и `import.meta.env` (ADR 0004 §13).
- [x] Конфиг Dependabot описан для проекта без бэкенда.

## Проверки

- Песочница вне проекта: эталонные конфиги ESLint фронтенда и `apps/api`, производный конфиг `packages/shared`, скрипты `format:check` и корневой `bun run --filter '*' check`.
- Проверка относительных ссылок во всех `.md`.

## Итог

- **Порядок старта:** бэклог идет в порядке PROMPT.md; шаг очистки удаляет историю шаблона при старте проекта; профиль записывается в PRODUCT.md после подтверждения итогового резюме.
- **Задачи вне кода:** документацию и инфраструктуру выполняет основной агент; уровень документации — по числу файлов и изменению правил, инфраструктура — не ниже Medium.
- **Охват проверок:** `format` и `format:check` покрывают корневые конфиги и `tests/`; `packages/shared` получил `check`; ESLint фронтенда запрещает прямое чтение `process.env` и `import.meta.env`. Эталонные `eslint.config.mjs` приведены к виду, который проходит собственные `format:check` и `perfectionist/sort-imports`: до правки порядок импортов в них нарушал это правило.
- **Проверки:** песочница вне проекта (Bun 1.4.4, ESLint с typescript-eslint 8.72, perfectionist 5.13, TypeScript 6.0): запрет чтения окружения срабатывает в модулях и не срабатывает в `env.ts` и `*.config.ts`; `bun fmt --check` с новыми шаблонами проходит на эталонных конфигах; `lint` и `typecheck` проходят в `packages/shared`. Скрипты пакетов запускались командами напрямую, а не через `bun run`.
- **Не исправлялось:** исполнитель для `packages/shared` в docs/workflow.md не определен.
