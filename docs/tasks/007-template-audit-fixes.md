# 007 — Аудит шаблона: ошибки, противоречия и устаревшие команды

- **Уровень:** Medium
- **Статус:** готово
- **Источники:** запрос пользователя на аудит и рефакторинг шаблона; [docs/setup/](../setup/common.md); ADR 0001–0023; npm registry (версии на 19.10.2026); документация [Bun](https://bun.com/docs/cli/run)
- **Цель:** инструкции и эталонные конфиги шаблона выполняются без ошибок на актуальных версиях пакетов, документы не противоречат друг другу.
- **Обоснование оценки:** только документация и эталонные конфиги, более 5 файлов, есть решения пользователя ([docs/workflow.md](../workflow.md) §1); прецедент — задача 006.

## Решения пользователя

- Инициализация в непустом корне шаблона — генератором во временной папке с переносом в корень; в монорепо — сразу в пустой `apps/web`.
- Порядок CSS-свойств — расширенный список по группам ADR 0009 §3.
- `docs/agents.md` переименован в `docs/workflow.md`: на файловых системах без учета регистра (Windows, macOS) агенты читали его как вложенный `AGENTS.md` папки `docs/`.
- Переменные продакшена разделены: `.env` — для compose, `api.env` — для контейнеров приложения.

## Критерии готовности

- [x] Эталонные ESLint-конфиги загружаются в ESLint 10 с perfectionist 5.
- [x] Эталонные стили и полные SCSS-примеры проходят эталонный Stylelint.
- [x] Команды инициализации выполняются без вопросов генераторов и не создают свой `AGENTS.md`.
- [x] TypeScript ставится в версии, совместимой с `typescript-eslint` и `@astrojs/check`.
- [x] Деплой Astro с адаптером Node, конфиг Nginx и секреты продакшена описаны корректно.
- [x] Относительные ссылки между документами работают.

## Проверки

- Эталонные конфиги и примеры кода из ADR прогнаны в песочнице вне проекта: ESLint 10.13 + typescript-eslint 8.71 + perfectionist 5.12, Stylelint 17.16 + stylelint-order 8.1, Prettier 3.
- `create-astro` 5.3 и `create-next-app` 16.4 запущены с новыми флагами в пустых папках.
- Проверка относительных ссылок во всех `.md` и поиск остатков исправленных формулировок.

## Итог

- **Критичные ошибки:** `newlinesBetween: 'always'` недопустим в perfectionist 5 (ESLint падал при загрузке конфига); `typescript@latest` (7.x) несовместим с `typescript-eslint` и `@astrojs/check`; генераторы не работали в непустом корне, задавали вопросы и создавали свой `AGENTS.md`; Astro читал сгенерированный `astro.config.mjs` вместо эталонного `astro.config.ts`; эталонные стили давали 16 ошибок Stylelint; при адаптере Node в корень Nginx выкладывался `dist/` вместо `dist/client/`; в конфиге Nginx не было сертификата; контейнеры API получали пароль суперпользователя PostgreSQL.
- **Противоречия:** ссылка ADR 0011 на несуществующее правило AGENTS.md, `src/assets/` вне дерева ARCHITECTURE.md, разные объявления `Window.ym`, правило ADR 0004 §11 против примеров, примеры, нарушающие собственный ESLint, мок формы и профиль `iPhone 14` в ADR 0014, описание оболочки `bun run`.
- **Не исправлялось (вне согласованного списка):** `packages/shared` не входит в `bun run check`; фронтенд-ESLint не проверяет запрет прямого чтения `process.env` и `import.meta.env` (ADR 0004 §13); пробелы в конце строк в примерах разметки ADR 0002.
