# История изменений шаблона

Версии шаблона — по SemVer: major — несовместимое изменение правил или структуры, minor — новые правила и эталонные конфиги, patch — исправления без изменения правил. Подробности каждой задачи — карточки в [docs/tasks/](docs/tasks.md).

Файл относится к шаблону, а не к проекту: при старте проекта версия записывается в [STATE.md](STATE.md), а файл удаляется ([PROMPT.md](PROMPT.md) «Завершение допроса»).

- **011:** порядок бэклога совпадает с PROMPT.md, шаг очистки истории шаблона, профиль в PRODUCT.md, уровни и исполнитель задач вне кода, `format` и `check` покрывают корневые конфиги и `packages/shared`, ESLint-запрет прямого чтения окружения, Dependabot для проекта без бэкенда.

- **009:** дизайн-навыки подчинены правилам шаблона, анти-шаблоны в docs/design.md §9.
