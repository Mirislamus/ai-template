# AI-Native Web Template

Профессиональный инженерный шаблон для создания сверхбыстрых веб-сайтов, лендингов и веб-сервисов с помощью AI-агентов и разработчиков.

Спроектирован с приоритетом на **максимальную производительность (Lighthouse 100)**, **строгую типобезопасность** и **чистую модульную архитектуру**.

> **Как использовать данный шаблон:** подробная пошаговая инструкция для разработчиков и AI-агентов по старту, ведению и сдаче проекта описана в файле [USAGE.md](USAGE.md).

---

## Технологический стек

- **Рантайм и пакетный менеджер:** [Bun](https://bun.sh) (`bun install`, `bun run`).
- **Язык:** TypeScript (строгий режим `strict: true`, тотальный запрет `any` и `enum`).
- **Фреймворки (по профилям):**
  - **Astro (SSG / Islands):** стандарт по умолчанию для лендингов, каталогов и контентных сайтов (0 Кб JS на первом экране).
  - **Next.js (App Router):** профиль для веб-сервисов, личных кабинетов и сложной серверной динамики.
- **Интерактивные компоненты:** React 19 (строго `function` declaration, плоские импорты, `ref` без `forwardRef`).
- **Стилизация:** SCSS Modules + семантические токены в CSS-переменных (8pt Grid, BEM-нотация).
- **Сетевой клиент и стейт:**
  - HTTP-клиент: `ky` (таймауты, автоповтор, хуки).
  - Серверный стейт: `@tanstack/react-query`.
  - Клиентский стейт: `nanostores` (межостровной в Astro), `zustand` (Next.js).
- **Формы и валидация:** `react-hook-form` + `zod` + `imask`.
- **Иконки и уведомления:** `lucide-react`, `sonner`.
- **Контроль качества:** Prettier, ESLint Flat Config, Stylelint, Vitest, Playwright.

## Быстрый старт

### Требования к окружению
- **Bun:** `>= 1.4.0`
- **Node.js:** `>= 24.0.0`

### Установка зависимостей
```bash
bun install
```
*Внимание: использование `npm`, `yarn` или `pnpm` запрещено во избежание конфликтов lock-файлов.*

### Запуск режима разработки
```bash
bun run dev
```

## Команды проекта

| Команда | Описание |
|---|---|
| `bun run dev` | Запуск локального сервера разработки |
| `bun run build` | Сборка проекта в продакшен |
| `bun run preview` | Локальный предпросмотр собранного проекта |
| `bun run check` | **Единый конвейер верификации качества** (Prettier + ESLint + Stylelint + Typecheck) |
| `bun run lint` | Запуск проверки линтерами (JS/TS и стили) |
| `bun run format` | Автоматическое форматирование кода через Prettier |
| `bun run typecheck` | Строгая проверка типов без генерации файлов (`astro check` / `tsc`) |
| `bun run test` | Запуск модульных тестов Vitest |
| `bun run test:e2e` | Запуск сквозных smoke-тестов Playwright |
| `bun run build:analyze` | Сборка с генерацией интерактивного отчета о размерах бандла |

## Архитектура кодовой базы (FSD-Lite)

Исходный код в папке `src/` организован по трехуровневой методологии FSD-Lite со строгим направлением зависимостей снизу вверх:

```text
src/
├── shared/          # Независимый базис: UI-кит (кнопки, инпуты), утилиты, типы, стили/токены
├── features/        # Законченные интерактивные сценарии (форма заявки, фильтр, переключатель темы)
├── widgets/         # Крупные композиционные секции страниц (шапка, подвал, hero, FAQ)
├── layouts/         # Базовые каркасы страниц (BaseLayout)
├── content/         # Astro Content Collections с проверкой схем через Zod
└── pages/           # Маршрутизация страниц
```
